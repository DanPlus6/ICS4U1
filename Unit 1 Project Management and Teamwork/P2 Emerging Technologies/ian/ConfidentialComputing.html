Confidential Computing

What is Confidential Computing?

Confidential Computing is a computational technique that focuses on protecting data in use. It is designed to protect against software, protocol, cryptographic, and basic physical and supply-chain attacks. Confidential Computing performs calculations in a hardware-based trusted execution environment (TEE), where it is a secure area of a main processor, which allows it to protect data. Confidential data is only allowed to be released into the TEE when it is deemed to be trustworthy, TEEs are evaluated to be trustworthy with attestation, a cryptographic process that assess whether to trust the program or environment.


Advantages

  • Indigenous Peoples are fighting for data sovereignty, where Indigenous peoples are a part of or in control of their own data collection, This means to store the user's data in their own devices instead of in the cloud or a server, which is owned by tech companies. Confidential Computing allows for assurance of data sovereignty, as data is stored in a TEE, where attestation can find the private key of the main processor of the TEE, allowing for their location to be found, providing assurance that whoever is accessing the data is not malicious, increasing data sovereignty.

  • Confidential Computing allows for data to remain protected while it is in-use, which can preserve data security and privacy even while processing, this allows for collaborative analysis and AI development to use sensitive data, unlocking new opportunities for revenue and speedens innovation, allowing for the economy to grow.

Disadvantages

  • As TEEs have to be created for each specific use case, the scalability of Confidential Computing is limited. Every time an organization needs to extend protection to a new database, it would require more time, and effort.

  • When implementing Confidential Computing, there might be compatibility issues with the current setup organizations have, this would need specialized hardware or re-architecturing applications to be installed, increasing the complexity of the system.
